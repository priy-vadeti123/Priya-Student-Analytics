# Student Performance Analytics Dashboard

Prepared for Priya — a Streamlit Big Data mini-project.

## Files
- `app.py` — Streamlit application
- `student_performance.csv` — 1,200 sample student records
- `requirements.txt` — dependencies

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Upload all three files to a GitHub repository. On Streamlit Community Cloud, create an app from that repository and set the main file path to `app.py`.

The sample data is synthetic and intended for demonstration.
